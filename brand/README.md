# SNG ONE brand files

| File | Use |
| --- | --- |
| `logo-lockup-dark.png` | Full logo for **dark** backgrounds (transparent) |
| `logo-lockup-light.png` | Full logo for **white / light** backgrounds (transparent) |
| `logo-mark.png` | The S1 truck without the words |
| `logo-s1.png` | Just "S1" (tiny sizes) |
| `app-icon-512.png` | App icon (rounded tile) |
| `bot-avatar.png` | Telegram bot picture: BotFather -> `/setuserpic` -> choose the bot -> send this file |
| `social-preview.png` | 1200x630 picture shown when a link is shared (also served at `/og.png`) |

The web app uses the copies in `web/public/` (logo, favicons, app icons, manifest). Source: the owner's logo sheet,
cut out and keyed to a transparent background.
